# Naturalee Museum

Public exhibition files for the digital art collection by daoyi2026.

Website: https://daoyi2026.github.io/naturalee-museum/

This repository contains the gallery and selected finished artworks only. Development history, drafts and original authoring files remain in a separate private repository. Artwork 002, Silver Clock — The Birds of Time, opens as a centered 450 × 600 canvas with no visible controls.

GitHub Pages serves the `main` branch from the repository root. Dependency licenses are retained with the published assets. No additional artwork license is assigned.
